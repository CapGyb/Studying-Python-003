# Studying-Python-003
Modele a classe LuminariaSmart com ID, estado (ligado/desligado) e intensidade (0 a 100, padrão zero). Implemente métodos para alternar seu estado e ajustar a intensidade com validação de limites. Ao final, instancie o dispositivo, ligue-o, defina o brilho em 75% e imprima o estado final.
